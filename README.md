# KawanMPASI 🍱👶

KawanMPASI adalah aplikasi Android yang dirancang untuk membantu orang tua dalam mengelola kebutuhan MPASI (Makanan Pendamping ASI) bayi.

Aplikasi ini menyediakan beberapa fitur utama yang berkaitan dengan profil bayi, jadwal MPASI, serta fitur interaktif untuk membantu penggunaan aplikasi menjadi lebih menarik.

## ✨ Features

- 👶 **Baby Profile**
  - Menyimpan dan menampilkan informasi bayi.
  - Nama bayi dapat digunakan dalam tampilan aplikasi.

- 🏠 **Home**
  - Menampilkan halaman utama aplikasi.
  - Menyediakan akses ke berbagai fitur KawanMPASI.

- 🎲 **Dice Roller**
  - Fitur permainan sederhana menggunakan dadu.
  - Menampilkan hasil dadu secara interaktif.

- 📅 **MPASI Schedule**
  - Menampilkan jadwal MPASI bayi.
  - Membantu orang tua mengatur waktu pemberian MPASI.

## 🛠️ Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Android Studio**
- **Gradle**

## 📱 Platform

KawanMPASI dikembangkan sebagai aplikasi **Android**.
